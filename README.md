Telegram AI Image Generator Bot
About
This is a Telegram bot built with Python that generates AI images using the Pollinations AI API.
Features
Generate AI images from text prompts.
Fast and easy to use.
Built with the python-telegram-bot library.
Uses the Pollinations AI image generation service.
How to Use
Start the bot on Telegram.
Send a text prompt (for example: "A futuristic city at sunset").
The bot generates and sends an AI image based on your prompt.
Technologies Used
Python
python-telegram-bot
Pollinations AI API
Installation
Clone this repository.
Install the required packages:
pip install -r requirements.txt
Add your Telegram bot token.
Run the bot:
python bot.py
Requirements
Python 3.10 or later
Internet connection
Telegram Bot Token
Disclaimer
This project uses the Pollinations AI service for image generation. Generated images are created by AI based on the user's text prompt.
